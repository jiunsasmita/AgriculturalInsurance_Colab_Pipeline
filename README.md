# AgriculturalInsurance_Colab_Pipeline
This repository provides a reproducible Python/Google Colab pipeline for
climate-informed agricultural insurance risk modeling and premium estimation.

The computational workflow integrates exploratory data analysis, construction
of the Agricultural Climate Risk Index (ACRI), agricultural risk-state
classification, transition-model estimation, expected-loss and insurance
premium calculation, and sensitivity analysis.

The workflow is designed to support transparent and reproducible empirical
analysis and to generate the tables, datasets, and figures used in the
associated research.
